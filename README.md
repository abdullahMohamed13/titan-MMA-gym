# WHAT THE HELL IS TITAN MMA GYM? 😡😡
ok ok chill! This is a mock-up booking system that allows you to book MMA (Mixed Martial Arts) classes.

## Class Booking Flow:
You sign in via our beautiful sign in page and boom, now you can book any class that you want. You will also receive confirmation via email. After that you can head to your dashboard and switch to any other plan you want [or cancel your current plan 😭].

## ✨UI features:

1. Home Page
- Hero section with promo video
- Overview of what the gym offers (About the gym, Routines, FAQ section, Newsletter Subscription section)

2. Classes Page:
- List of available classes (e.g., MMA, Muay Thai, Wrestling, Striking)
- Class details: coach, schedule, price, difficulty level
- Gallery section that holds unique training pics

3. Coaches Page
- Profiles of all coaches
- Background, achievements, specializations
- Testimonials section

4. Students Page
- Table that holds our top gym members & achievements, that's fetched from an external API using ReactQuery

## 🎯Target Users:
- MMA enthusiasts, current and potential students
- Visitors interested in training or purchasing MMA gear
- Gym members looking to stay updated with events and class schedules

## 🛠️Tech Stack:
- Frontend: React.js + TailwindCSS + Typescript
- UI Library: Material UI (MUI)
- Authentication & Billing: Clerk
- Database: Convex
- Hosting: Netlify
- Build Tool / Bundler: Webpack
