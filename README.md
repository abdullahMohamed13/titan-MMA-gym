# titan-MMA-gym

🧩 Main Features:

1. Home Page
Hero section with promo video
Overview of what the gym offers (classes, faq [until-now])

2. Classes Page
List of available classes (e.g., MMA, Muay Thai, Wrestling, Striking)
Class details: coach, schedule, price, difficulty level
Button to book a spot

3. Coaches Page
Profiles of all coaches
Background, achievements, specializations

4. Events Page
Not builed yet

5. Students Page
Spotlight on gym members or achievements
Testimonials, photos, and rankings

6. E-Commerce Section
Shop for MMA gear (gloves, rashguards, shorts, accessories)
Product filters by category and size
Cart, checkout, and payment integration

7. Booking System
Book classes directly from the class page
Select date, time, and coach (if applicable)
Receive confirmation via email or dashboard

🎯 Target Users:
MMA enthusiasts, current and potential students

Visitors interested in training or purchasing MMA gear

Gym members looking to stay updated with events and class schedules

🛠️ Tech Stack (Suggested):
Frontend: React.js + TailwindCSS / MUI

Payment: Stripe / PayPal

Hosting: Vercel / Netlify (Frontend), Render / Heroku / AWS (Backend)
